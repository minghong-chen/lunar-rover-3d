## Entry points / 入口文件

| File | Purpose | Needs a server? |
|---|---|---|
| `dist/lunar-rover-standalone.html` | **Self-contained scene.** Open directly in a browser. Loads Three.js from unpkg CDN. | No |
| `index.html` | Modular build entry. Loads `src/main.js`. Three.js from CDN. | **Yes** (`npm start`) |
| `index.offline.html` | Generated by `npm run vendor`; imports a local copy of Three.js. | **Yes** |

> `index.offline.html` and `vendor/` are **not** in the ZIP — they are generated
> locally by `npm install && npm run vendor`. This keeps the archive small and
> avoids redistributing Three.js.
>
> `index.offline.html` 与 `vendor/` **不在** ZIP 中 —— 它们由
> `npm install && npm run vendor` 在本地生成，以保持压缩包精简并避免再分发 Three.js。

## Assets / 资源

**None required.** Every texture is drawn into an offscreen canvas at startup;
every mesh is composed from Three.js primitives. There are no image, model,
font, audio or HDR files in this repository, and no asset path can break.

**无需任何资源文件。** 所有贴图在启动时绘制到离屏 canvas，
所有网格由 Three.js 基础几何体组合而成。
仓库中不存在图片、模型、字体、音频或 HDR 文件，也就不存在资源路径失效的可能。

The only external dependency is Three.js r160, loaded from
`https://unpkg.com/three@0.160.0/` by the two CDN entry points. Run
`npm run vendor` to eliminate that network dependency entirely.

唯一的外部依赖是 Three.js r160，由两个 CDN 入口从
`https://unpkg.com/three@0.160.0/` 加载。运行 `npm run vendor` 可彻底消除该网络依赖。
